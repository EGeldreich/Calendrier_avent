# Advent Calendar  

## ✍️ Description  

### Brief explanation  
-   A project created for an internal competition at my training center.  
-   The goal was to develop an Advent Calendar with interactive features.  

### Learning objectives  
-   Implement randomization for number placement, colors, and box sizes.  
-   Manage modals and sequential unlocking mechanics.  
-   Use JavaScript to enforce date restrictions and localStorage for state persistence.  

## 📜 Guidelines  
-   Implement as much of a list of specified features as possible
-   Once must-have features are done, feel free to add some more

## 💪 Own Challenge  
-   Working in complete autonomy on the project.  
-   Implementing multiple new JavaScript concepts at once.  

## 🚀 Features  
-   **Randomized layout**: Numbers, colors, and box sizes are shuffled.  
-   **Sequential unlocking**: Boxes must be opened in order.  
-   **Date restriction**: Prevents users from opening future boxes.  
-   **Modal system**: Displays content when a box is clicked.  
-   **LocalStorage integration**: Keeps track of opened boxes.  

## 🛠️ Technologies Used  
-   HTML, CSS, JavaScript (LocalStorage, Date handling)  

## 🤔 Challenges Encountered  
-   Managing the logic for sequential unlocking.  
-   Handling multiple new JavaScript features effectively.  
-   Ensuring a smooth and user-friendly experience.  

## 🔮 Possible Improvements

-   Modals could be more sophisticated
